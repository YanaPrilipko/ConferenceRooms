# ConferenceRooms

`ConferenceRooms` — ASP.NET Core Web API для керування конференц-залами та бронюваннями.

## Можливості

- перегляд списку залів;
- створення, оновлення та видалення залів;
- пошук доступних залів за датою, часом і місткістю;
- створення бронювання з вибором додаткових послуг;
- автоматичний розрахунок вартості бронювання;
- Swagger UI для тестування API.

## Технології

- .NET 8
- ASP.NET Core Web API
- Swagger / OpenAPI
- In-memory зберігання даних

## Запуск

1. Відкрити проєкт `ConferenceRooms.csproj`.
2. Запустити застосунок у режимі `Development`.
3. Відкрити Swagger UI для перевірки запитів.

## API

### `GET /api/rooms`
Повертає всі конференц-зали.

### `POST /api/rooms`
Створює новий зал.

### `PUT /api/rooms/{id}`
Оновлює існуючий зал.

### `DELETE /api/rooms/{id}`
Видаляє зал.

### `GET /api/rooms/available`
Повертає доступні зали за параметрами:
- `start`
- `end`
- `capacity`

### `POST /api/bookings`
Створює бронювання.

## Моделі запитів

- `RoomDto`
- `BookingDto`
- `ServiceOptionDto`

## Примітки

- Дані зберігаються в пам’яті та скидаються після перезапуску.
- Додано глобальне обмеження запитів: 100 запитів за хвилину.
